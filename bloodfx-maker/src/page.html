Install

Unzip bloodfx-maker.zip, then:

  1. Close FiveM.
  2. Tracer: put the .rpf from the zip's mods folder in
    %localappdata%\FiveM\FiveM.app\mods
    Remove the old copy of that pack, and keep only one tracer pack there.
  3. Blood: put bloodfx.dat in
    %localappdata%\FiveM\FiveM.app\citizen\common\data\effects
    Make the folders if they're missing. Back up any bloodfx.dat already there.
  4. Start FiveM. Servers that block client mods ignore these files.
